# 日本語チェックフック

Claude Code の返答に AI 特有の言い回しが混ざったら、ターンを終わらせずに書き直させる Stop フック。
プロンプトやスキルと違って、モデルではなくハーネスが実行するので、会話が長くなっても無視されない。

## 全プロジェクトで自動で動かす

```bash
bash .claude/hooks/install.sh
```

`~/.claude/hooks/` にスクリプトとルールを置き、`~/.claude/settings.json` の `Stop` に登録する。
既存の設定はマージされ、`settings.json.bak` にバックアップが残る。新しいセッションから有効になる。

このリポジトリだけで試す場合は `.claude/settings.json` に登録済みなので、そのまま使える。

## 動き

```
Claude が普通に返答
  ↓ Stop フック発火
① transcript から、直近のユーザー発話以降の assistant テキストだけ抜く
② コードブロック・インラインコード・URL・パス・引用行・鉤括弧の中を除去
③ かなが無い / 30字未満 / ツールだけのターン → 素通り
④ ja-ng-phrases.json と正規表現で照合（hard は1件、soft は2件で差し戻し）
⑤ 250字以上なら Haiku に文脈判定させる（前口上・決め文・言い換え・文末の連続・冗長）
   質問文も渡すので、一言で済む質問に長く答えた場合も捕まる
⑥ 違反あり → decision:block。実際に出力した文の引用と、校正済みの全文を返す
⑦ 同一ターン1回まで。それ以上は諦めて通す（表示は最大2回）
```

②〜④は 0.03 秒程度で終わる。⑤が走ると 15〜20 秒かかるので、短い返答では呼ばない。

鉤括弧の中を除去するのは、NG 表現を例として示したときに自分が書いた文だと誤判定されるため。
地の文に同じ表現が出れば従来どおり捕まる。

差し戻しの理由文にはルールを書かない。実際に書いた文を引用する。抽象的な指示だと同じものを書くため。

校正済みの全文が添えられていれば、本体は貼り直すだけで済むので 1 往復で終わる。

## 長文パイプライン

`.claude/agents/ja-proofreader.md` と `CLAUDE.md` が対になっている。長文は画面に
直接書かず、下書きを `.md` に書き、`ja-proofreader` に渡して書き換えさせ、その中身を
一度だけ出す。サブエージェントの出力は画面に出ないので、表示は 1 回で済む。

フックはその外側で効く。パイプラインを通さなかった場合の受け皿になる。

## 表現を足す

`~/.claude/ja-ng-phrases.local.json` を作ると、本体のルールにマージされる（同じ `pattern` は後勝ち）。

```json
{
  "rules": [
    { "pattern": "腹落ち", "label": "AI定型", "fix": "削除する", "severity": "hard" },
    { "pattern": "様々な", "severity": "off" }
  ]
}
```

- `severity: "hard"` — 1件で差し戻す
- `severity: "soft"` — 2件以上で差し戻す
- `severity: "off"` — 本体のルールを無効化する

嫌な言い回しに出くわしたら、ここに 1 行足す。使うほど当たるようになる。

## 環境変数

| 変数 | 既定 | 内容 |
| --- | --- | --- |
| `JA_CHECK_DISABLE` | - | `1` で完全に無効化 |
| `JA_CHECK_MODE` | `hybrid` | `regex`（速い、LLM を呼ばない） / `hybrid` / `llm`（毎回 LLM） |
| `JA_CHECK_MODEL` | `claude-haiku-4-5-20251001` | 判定に使うモデル |

## 制限

- CLI では最初の返答が一度画面に出てから書き直しが続く。テキストは既に流れているので消せない。最終メッセージが清書版になる。
- `Stop` にだけ登録している。`SubagentStop` には登録しない（サブエージェントの中間出力まで検閲すると壊れる）。
- 判定用の `claude -p` は `--setting-sources ''` で起動するので、フックは再帰しない。
